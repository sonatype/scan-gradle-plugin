## Version 4.0.0 (July 29, 2026)
* Dropped support for Gradle before 8.4 and upgraded to Java 17

## Version 3.1.6 (June 18, 2026)
* Maintenance release

## Version 3.1.5 (March 27, 2026)
* Enabled publishing to Gradle Plugins portal

## Version 3.1.4 (September 22, 2025)
* Added support for analyzing Java 21 bytecode

## Version 3.1.3 (August 14, 2025)
* Maintenance release

## Version 3.1.2 (July 31, 2025)
* Maintenance release

## Version 3.0.0 (December 13, 2024)
* Upgraded the Java version to 11 and added support for Gradle 5.0 to 8.3
* Reduced the plugin's artifact size

## Version 2.8.3 (August 16, 2024)
* Maintenance release

## Version 2.8.1 (April 27, 2024)
* Maintenance release

## Version 2.8.0 (April 26, 2024)

## Version 2.7.0 (January 19, 2024)
